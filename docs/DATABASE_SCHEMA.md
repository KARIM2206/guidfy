# 🗄 Database Design & Prisma Models

Guidfy uses a relational database (MySQL/PostgreSQL) managed by **Prisma ORM** to ensure type safety, robust migrations, and clean data modeling. This document outlines the core entities and their relationships.

---

## 1. Core Entities Overview

The database is structured around several domains that power the application:

1. **Authentication & Identity:** `User`, `Role`
2. **Educational Content:** `LearningPath`, `Roadmap`, `Step`, `Lesson`, `Quiz`
3. **Progress Tracking:** `UserRoadmapProgress`, `UserLessonProgress`, `QuizAttempt`
4. **Community & Engagement:** `Community`, `Post`, `CommunityQuestion`, `Answer`, `Vote`, `Comment`
5. **Career & Opportunities:** `Job`, `JobApplication`, `Report`

---

## 2. Entity-Relationship Highlights

### Users & Roles
Users in Guidfy are categorized by the `Role` enum (`STUDENT`, `ADMIN`, `SUPER_ADMIN`). A user can be enrolled in many roadmaps, create posts, apply for jobs, and have multiple AI-generated career reports.

### Learning Paths & Roadmaps
A `LearningPath` (e.g., Frontend Developer) consists of multiple `Roadmaps` (e.g., React, CSS). 
Each `Roadmap` contains multiple `Steps`, and each `Step` contains `Lessons` (Video, Article, or Quiz).

### Community
The community is broken down into `Posts` (general sharing) and `CommunityQuestions` (Q&A). Both can receive `Votes`, `Comments`, and `Answers`.

## 3. Core Prisma Schema (Data Dictionary)

Below are the simplified versions of the critical Prisma models demonstrating the core database architecture.

### A. The User Model
The central model that connects to almost every other entity in the system.

```prisma
enum Role {
  STUDENT
  SUPER_ADMIN
  ADMIN
}

model User {
  id               Int       @id @default(autoincrement())
  email            String    @unique
  name             String?
  password         String
  role             Role      @default(STUDENT)
  title            String?   // Job Title
  avatar           String?   
  experienceYears  Int?

  // Progress Relations
  enrolledRoadmaps      UserRoadmap[]
  lessonProgress        UserLessonProgress[]
  quizAttempts          QuizAttempt[]
  
  // Community Relations
  posts                 Post[]
  questions             CommunityQuestion[]
  
  // Career Relations
  reports               Report[]
  jobApplications       JobApplication[]
}
```

### B. Learning Paths & Roadmaps
The hierarchy of educational content.

```prisma
enum RoadmapStatus {
  DRAFT
  ASSIGNED
  IN_PROGRESS
  REVIEW
  PUBLISHED
}

model LearningPath {
  id          Int       @id @default(autoincrement())
  title       String    @unique
  description String    @db.Text
  roadmaps    Roadmap[] // One-to-Many
}

model Roadmap {
  id              Int           @id @default(autoincrement())
  title           String
  description     String?       @db.Text
  status          RoadmapStatus @default(DRAFT)
  learningPathId  Int?
  learningPath    LearningPath? @relation(fields: [learningPathId], references: [id])
  
  steps           Step[]        // Steps within the roadmap
}
```

### C. Community Q&A
The structure powering the social interaction platform.

```prisma
model CommunityQuestion {
  id          Int       @id @default(autoincrement())
  title       String
  body        String    @db.Text
  authorId    Int
  author      User      @relation(fields: [authorId], references: [id])
  
  answers     Answer[]
  votes       Vote[]
  tags        Tag[]     // Many-to-Many
  createdAt   DateTime  @default(now())
}

model Answer {
  id          Int               @id @default(autoincrement())
  body        String            @db.Text
  isAccepted  Boolean           @default(false)
  authorId    Int
  author      User              @relation(fields: [authorId], references: [id])
  questionId  Int
  question    CommunityQuestion @relation(fields: [questionId], references: [id])
}
```

### D. AI Career Reports
Stores the insights generated by the Python FastAPI service.

```prisma
model Report {
  id          Int      @id @default(autoincrement())
  userId      Int
  user        User     @relation(fields: [userId], references: [id])
  
  data        Json     // Stores the AI prediction JSON payload
  createdAt   DateTime @default(now())
}
```

> [!NOTE]  
> **Database Migrations**
> When modifying the schema in `backend/prisma/schema.prisma`, always run `npx prisma generate` to update the Prisma Client, followed by `npx prisma migrate dev` to apply changes to the local database.
